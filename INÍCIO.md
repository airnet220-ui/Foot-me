## 🔄 Como a API Funciona

```
┌─────────────┐
│ Página ativa│
└──────┬──────┘
       │
       ▼
┌─────────────────────────────┐
│ script.js tenta API         │
│ (com sua chave de API)      │
└──────┬──────────────────────┘
       │
       ├─ API responde ✅
       │  └─> Atualiza placares com dados REAIS
       │
       └─ API falha ❌
          └─> Mostra dados padrões
       
┌──────────────────────────┐
│ A cada 30 segundos:      │
│ Busca dados novos        │
│ Atualiza seção de placar │
└──────────────────────────┘
```

```
1. Abra index.html
2. Pressione F12 (DevTools)
3. Vá em Console
4. Procure por mensagens:

   ❌ "Erro na API: 401" → Chave inválida
   ⚠️  "Usando dados padrões" → API não configurada
```
